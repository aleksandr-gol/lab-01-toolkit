# Лабораторная работа 1 — Toolkit

Консольный калькулятор и конвертер величин на Python 3.10+.
Вычислительное ядро отделено от интерфейса командной строки.

## Возможности

- Калькулятор: целые и дробные числа, унарные знаки, операции `+`, `-`, `*`, `/`, `//`, `%`.
- Алгоритм E4: два прохода с соблюдением приоритета операций, без скобок.
- Конвертер: длина (`mm`, `cm`, `m`, `km`), масса (`g`, `kg`), температура (`c`, `f`, `k`).
- Коэффициенты конвертации загружаются из `units.json`; регистр единиц не учитывается.
- Проверяются неправильный ввод, деление на ноль, несовместимые единицы и температура ниже абсолютного нуля.

Вычисления используют `float`, поэтому возможны небольшие погрешности.
Ошибки выводятся в `stderr` с кодом завершения `2`, успешные команды — с кодом `0`.
Дополнительные задания: операции `//` и `%`, таблица конвертаций в JSON.

## Структура

- `src/toolkit/calculator.py` — токенизация, проверка и вычисление выражений.
- `src/toolkit/converter.py` и `units.json` — перевод величин и таблица коэффициентов.
- `src/toolkit/__main__.py` — CLI на основе `argparse`.
- `src/toolkit/errors.py` — общее исключение `ToolkitError`.
- `tests/` — тесты калькулятора, конвертера и CLI.
- `pyproject.toml` — настройки пакета, pytest и Ruff.

## Установка и использование

Установка из корня проекта, включая инструменты проверки:

```shell
python -m pip install -e ".[dev]"
python -m toolkit --help
python -m toolkit calc "2 + 3 * 4"
python -m toolkit calc "-7 // 3"
python -m toolkit convert 1 --from km --to m
```

## Проверка

```shell
python -m pytest
ruff check .
```
